Project notes

How the site was made

An eight-page student website built by a three-person team with semantic HTML and Bootstrap.

Three people

Team responsibilities

Everyone can explain the shared header, navigation, colours and responsive layout. Each member also has two main content pages to present.

  1. Sanzhar — Menu and Feedback
    Menu table, ordering notes and review form.
  2. Jasulan — Visit and Gallery
    Contact details, map and photo grid.
  3. Madi — About and FAQ
    Restaurant story, questions and contact form.

Simple structure

Built for clear explanation

Bootstrap supplies the layout and responsive navigation. The project keeps semantic elements, relative links and a small brand stylesheet.

HTML and CSS

What the main pieces do

Semantic HTML

header, nav, main, section and footer describe the page structure.

Reusable classes

Classes such as container, row, col-lg-6 and btn keep the pages consistent.

Responsive layout

Bootstrap breakpoint classes change columns at phone, tablet and desktop widths. The bundled collapse component controls the mobile menu.
