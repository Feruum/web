Project notes

How the site was made

An eight-page student website built by a three-person team with plain HTML and CSS.

Three people

Team responsibilities

Everyone can explain the shared header, navigation, colours and responsive layout. Each member also has two main content pages to present.

  1. Sanzhar — Menu and Feedback
    Menu table, ordering notes and review form.
  2. Jasulan — Visit and Gallery
    Contact details, map and photo grid.
  3. Madi — About and FAQ
    Restaurant story, questions and contact form.

Simple structure

Built for clear explanation

No framework and no JavaScript. The project uses semantic elements, relative links and a small set of reusable CSS classes.

  • Pages8 HTML files
  • Shared designcss/base.css
  • Page styles3 named CSS files
  • Forms3 practice forms
  • ImagesLocal JPG files

HTML and CSS

What the main pieces do

Semantic HTML

header, nav, main, section and footer describe the page structure.

Reusable classes

Classes such as site-shell, page-hero, content-grid and button keep the pages consistent.

Responsive layout

CSS media queries change two-column areas into one column on small screens. Images use object-fit: cover so they fill their frames.
